## 📖 About

**Powu** makes UPI payments possible **without internet**, using India's **\*99#** USSD-based banking service (NPCI). When mobile data isn't available, Powu lets you initiate UPI payments through your mobile network alone — no internet connection required.

📦 **App size:** just **1.8 MB** — light enough for any phone, even with low storage.

## ✨ What You Can Do With POWU

</div>

| | Feature | Description |
|:---:|:---|:---|
| 📴 | **Works Without Mobile Data** | Uses the `*99#` USSD service to access supported UPI banking services — no internet needed. |
| 💸 | **Make UPI Payments** | Send money directly from your bank account using UPI, even when connectivity is down. |
| 📷 | **Pay via QR Code** | Scan any UPI QR code to pay instantly, without needing to type in details. |
| 🆔 | **Pay via UPI ID** | Send money directly using a UPI ID (VPA) — fast and error-free. |
| ☎️ | **Pay via Phone Number** | Transfer funds straight to a mobile number linked with UPI. |
| 🏦 | **Account Transfer** | Send money directly to a bank account using account number & IFSC. |
| 🧾 | **Check Transaction History** | View and track all your past payments and transfers in one place. |
| 📱 | **Simple & Lightweight** | A straightforward app experience with no complicated setup. |
| 🌐 | **Works in Low-Connectivity Areas** | Ideal for poor network coverage zones or when mobile data is simply turned off. |
| 🔒 | **Bank-Powered & Secure** | Transactions run through supported UPI/USSD banking infrastructure — Powu never holds your money. |

## ⚙️ How It Works

</div>

<div align="center">

1. **Open** the Powu app
2. **Enter** the required payment details
3. Powu **initiates** the `*99#` USSD service
4. **Follow** the instructions provided by your bank / UPI service
5. **Authorize** the transaction using your UPI PIN

> ⚠️ Availability and functionality depend on your bank, mobile network, and the services supported through `*99#`.
